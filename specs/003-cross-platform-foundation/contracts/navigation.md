# Contract: Navigation Routes (expo-router)

**Feature**: `003-cross-platform-foundation` | **Date**: 2026-10-04

## Route Map (file-based, typed)

| Route | File | Screen | Purpose |
|---|---|---|---|
| `/` | `app/(tabs)/index.tsx` | Home | Recents list + Scan / Photos / Files / Attribution actions |
| `/attribution` | `app/(tabs)/attribution.tsx` | Attribution | License/credit screen |
| `/scan` | `app/scan.tsx` | ScanReview | Camera capture with review (retake/crop/page list) |
| `/import/photos` | `app/import/photos.tsx` | PhotoPicker | Gallery import |
| `/import/files` | `app/import/files.tsx` | FilePicker | File import (images + PDF) |
| `/ocr/:docId` | `app/ocr/[docId].tsx` | OcrProgress | Per-page OCR status → Reader when done |
| `/reader/:docId` | `app/reader/[docId].tsx` | Reader | Original\|Text toggle, font size, Trad/Simp, pink-ink underline |

## Typed Navigation (TypeScript)

```typescript
// types/expo-router.d.ts (generated by expo-router)
declare module 'expo-router' {
  export interface ExpoRouterRoutes {
    '/': undefined;
    '/attribution': undefined;
    '/scan': undefined;
    '/import/photos': undefined;
    '/import/files': undefined;
    '/ocr/:docId': { docId: string };
    '/reader/:docId': { docId: string };
  }
}
```

Usage:
```typescript
import { router } from 'expo-router';
router.push('/reader/' + docId);        // type-checked
router.push({ pathname: '/ocr/' + docId }); // type-checked
```

## Navigation Contracts

- **Home → Scan**: `router.push('/scan')` → returns scanned pages via callback
- **Home → Import Photos**: `router.push('/import/photos')` → returns images
- **Home → Import Files**: `router.push('/import/files')` → returns files/PDF
- **Scan/Import → OCR**: `router.push('/ocr/' + docId)` with pages added to DB
- **OCR → Reader**: Auto-navigate when all pages `recognized` or user taps page
- **Reader → Home**: Back gesture or header back button
- **Deep links**: `/reader/:docId` and `/ocr/:docId` support direct open

## Accessibility

- All tab/stack screens have `accessibilityLabel` on tab bar icons
- Header back buttons have `accessibilityLabel="Back"`
- Focus order follows visual layout (top-to-bottom, left-to-right)
- Dynamic Type respected (font sizes scale with system setting)
